# Android 首页视觉基准

更新时间：2026-07-19

- 当前 Android 工作树只读代码：`main.dart`、`home_view.dart`、`home_summary_card.dart`、`record_input_bar.dart`、`transaction_day_list.dart`、`app_colors.dart`。

## 首页不可偏离项

- 暖橙到奶白的整页背景；状态栏以下不出现系统大标题。
- 顶栏顺序为：左侧圆形菜单、右侧圆形搜索、最右账本胶囊。
- 汇总卡左右 16、圆角 20；左上年月和统计胶囊，猫从右上探出并贴紧卡边。
- 有预算时显示剩余预算、收入/支出、动态进度条、百分比、总预算、剩余天数和今日可用圆环。
- 三段筛选顺序固定为全部、支出、收入；到汇总卡和账单日卡的间距一致。
- 账单按天白色玻璃卡分组；卡头显示日期和当日收支，行内显示图标、标题、小字、金额及状态。
- 底部固定玻璃输入卡，上层内容通过渐变隐入；文案“记一记”，工具行为加号、记账模式胶囊和上箭头。
- 根导航没有底部 Tab；左抽屉在底层，主页整体向右推开。

## 当前实现边界

第一里程碑只展示真实的无预算状态和手动记账入口。预算、统计和 AI 数据层接入前，禁止用假金额、假回复或无效可点击入口伪装完成。
